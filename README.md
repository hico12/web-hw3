## 어려웠던 점 3가지와 해결
1. **동적 생성 카드의 개별 이벤트 처리 문제**: 검색이나 정렬로 카드가 다시 그려질 때마다 하트 버튼 이벤트가 사라지는 문제가 있었으나, 부모 컨테이너(`.board`)에 한 번만 리스너를 등록하는 이벤트 위임(`e.target.classList.contains("like")`, `e.target.closest(".card")`)으로 해결함.
2. **검색·정렬·보기 필터 간 상태 충돌**: 검색어 입력 후 정렬이나 라디오 필터를 바꾸면 이전 조건이 풀리는 현상을 막기 위해, 현재 입력된 모든 조건을 순차적으로 계산해 최종 배열을 반환하는 `getView()` 단일 함수 구조로 통합하여 해결함.
3. **TMDB 이미지 경로 결합 오류 (`ERR_NAME_NOT_RESOLVED`)**: 템플릿 리터럴에서 포스터 경로 앞에 이미지 서버 도메인(`https://tmdb.org`)과 `$` 기호가 누락되어 이미지가 깨졌으나, 개발자 도구 콘솔 에러를 확인해 경로 문자열을 수정하여 해결함.
